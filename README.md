# Forever

Forever — веб-мессенджер RKC Studio.

## Текущая структура

- `index.html` — разметка приложения.
- `styles.css` — стили и адаптивная вёрстка.
- `app.js` — клиентская логика и обращения к Supabase.
- `docs/TECHNICAL_AUDIT.md` — первичный технический аудит и план модернизации.

Проект пока остаётся статическим веб-приложением: сборщик и npm-зависимости не требуются. Supabase JS загружается через CDN.

## Локальный запуск

Откройте терминал в корне проекта и запустите простой HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте:

```
http://localhost:8000
```

Не рекомендуется запускать приложение через URL `file://`: используйте локальный HTTP-сервер или настроенный хостинг.

## Backend

Клиент использует Supabase Auth и таблицы с префиксом `forever_`. Для полноценной работы необходим существующий Supabase-проект с настроенными таблицами, индексами, ограничениями, политиками Row Level Security и параметрами Auth.

**Важно:** в репозитории пока нет воспроизводимой SQL-схемы и миграций. Не создавайте таблицы наугад и не запускайте destructive SQL на действующем проекте. Сначала необходимо получить актуальную схему и RLS-политики.

## Статус

Проект находится в процессе восстановления и модернизации. Разделение HTML, CSS и JavaScript — первый подготовительный шаг; оно само по себе не означает, что все функции уже протестированы или исправлены.
